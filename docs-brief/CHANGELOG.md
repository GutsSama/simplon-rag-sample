# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

### Added
- **Streaming Tokens**: Real-time typewriter effect in Streamlit UI using FastAPI StreamingResponse.
- **Hybrid Architecture**: Support for running Ollama natively on macOS host for Metal acceleration while keeping the stack in Docker.
- **Healthchecks**: Improved Docker Compose stability with API healthchecks and service_healthy conditions.
- **Metadata Sentinels**: Robust parsing of metadata (sources) at the end of token streams.
- **Improved UI**: Space Grotesk typography and custom CSS styling for chat bubbles.
- **Documentation**: New guides for Ollama optimization and CLI usage.
